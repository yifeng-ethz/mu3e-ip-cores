# Contributing

Contributions are accepted under the Apache License 2.0. By submitting a
contribution, you agree that it may be distributed under that license and
certify that you have the right to submit it.

## Developer Certificate of Origin

Every commit in a contribution must include a `Signed-off-by` trailer under
the [Developer Certificate of Origin 1.1](DCO). Add it automatically with:

```bash
git commit --signoff -m "Describe the change"
```

The resulting commit message ends with:

```text
Signed-off-by: Your Name <you@example.com>
```

Use your real name and an email address that matches the commit author. The
sign-off is a certification under the DCO, not a copyright assignment or a
Contributor License Agreement.
