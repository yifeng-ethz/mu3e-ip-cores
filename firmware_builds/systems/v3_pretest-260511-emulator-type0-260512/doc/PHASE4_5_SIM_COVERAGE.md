## Evidence Contract

Each `sim_evidence/<row_id>/` directory contains:

- `sim_counters.json`: row config, run-control opcodes, arb lane counters, emulator counters, histogram counters, rbCAM placeholder counters, and MTS status placeholders.
- `sim_hist_bin.csv`: 256 extractable histogram rows (`bin_idx,count`).
- `sim_plot_rate.png`: rate/channel histogram rendered through `scripts/cotest/phase4_5_plot.py`.
- `sim_plot_latency.png`: latency placeholder plot rendered through the same plot module; the compact harness has no rbCAM timestamp split.
- `transcript.log`: Questa transcript with the `P45_SIM_ROW_PASS` line for that row.

## Notes

- The lane-mask zero sanity rows are `p45_025_lane_none_default_default_dir` and `p45_031_lane_none_0x00000001_default_dir`; both pass with `sim_total_hits=0`.
- All nonzero lane-mask rows pass the directed predicate `sim_total_hits > 0`.
- `hit_mode` is written through the emulator `SIGNAL` CSR in the generated row modules; `MUTRIG_FORMAT` remains the type0 format enable value.
- `histogram_statistics_v2` configuration mirrors the on-board sweep defaults: `LEFT_BOUND=0`, `RIGHT_BOUND=255`, `BIN_WIDTH=1`, `KEY_LOC=channel_post`, and `INTERVAL_CFG=0xFFFFFFFF`.
