Phase-6 End-to-End Progress

The active SWB/ER OPQ profile is Mu3e Demo: N_SHD=128, N_HIT=255. Therefore the host-disk proof for this checkpoint is 255 delivered same-timestamp hits plus exactly one accounted OPQ drop_hit per 256-hit source cluster, with adjacent bunch timestamps matching the 100 kHz cadence.
