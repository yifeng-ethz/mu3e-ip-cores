**Total:** 192 cases (1 implemented / 0 waived)

**Methodology key:**
- **D** directed - single deterministic stimulus with a golden expectation.
- **R** constrained-random - UVM sequence randomizes the named axis and the scoreboard checks count parity.

This file is the BASIC bucket for happy-path SWB run-control, slow-control, and datapath flow in the SWB rdma_pretest-260511 integration build.
