## Debug Ladder

| Observation | Interpretation | Next step |
|---|---|---|
| CSR write occurs, `csr.mode` stays `0` | live address or CSR decode mismatch | re-check `mutrig_injector_0.csr` base `0x0AC80` and SVD/register-map extraction; do not use `phase5_injector_jtag_preset.tcl` for datapath CSRs because the generated JTAG master is not connected to `mm_bridge.s0` |
| `csr.mode = 2`, but no `periodic_injector_pulse` | injector register programming or clock/reset issue | check `pulse_interval`, `pulse_high_cycles`, `reset_out`, and `lvds_outclock_clk` |
| injector `coe_inject_pulse` toggles, but fanout out0 does not | Qsys conduit/fanout boundary issue | inspect `pulse_fanout8:emulator_inject_fanout` generated wiring and recompile |
| fanout out0 toggles, but `emulator_mutrig_0.inject_pulse_clk` does not | emulator conduit boundary or optimization issue | inspect `emulator_mutrig_0.coe_inject_pulse` and synchronizer taps |
| emulator accepts the pulse, but MTS/histogram stay zero | post-emulator datapath issue | move to BASIC T0->T4 tap set and compare against `INJ-P0-SIM` |
| emulator path passes but real path stays zero | MuTRiG config / LVDS training / physical lane issue | rerun XML cfg with frame receiver and LVDS error-counter probes; debug lane training before crediting A2/P4/P8/P9 real-source cases |
| real path has MTS/histogram hits but ring input-error or MTS discard counters increment | intermittent MTS timestamp-error / delay calibration issue before or inside MTS filtering | keep the MTS-error trigger STP armed for soak; do not mark as PASS with `ring_filter_inerr=off` or with any nonzero MTS discard |
